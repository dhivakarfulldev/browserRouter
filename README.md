# 🚀 React BrowserRouter

A simple React project demonstrating **client-side routing using BrowserRouter and Link** from React Router DOM.


## ✨ Features

- ⚛️ Built with React.js
- 🧭 Client-side routing using `BrowserRouter`
- 🔗 Page navigation using `Link`
- 📄 Multiple pages and routes
- 🚫 404 / Not Found page
- 🔄 Navigation without full page reload
- 📱 Responsive user interface
- ⚡ Fast development with Vite

## 🛠️ Technologies Used

- **React.js**
- **React Router DOM**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **Vite**
- **Git & GitHub**

## 🧭 React Router

This project uses `BrowserRouter` and `Link` for client-side navigation.
